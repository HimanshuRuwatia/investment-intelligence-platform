## Architectural Decisions

1. **Single package** — modular monolith; no `packages/` or `apps/` yet.
2. **ESM + strict TypeScript** — `"type": "module"`, `module`/`moduleResolution`: `NodeNext`.
3. **Tooling** — Vitest, ESLint flat config, Prettier (not named in docs; chosen for M1.1).
4. **Minimal CLI** — pure `process.argv`; returns structured `{ exitCode, stdout, stderr }` for testability.
5. **Architecture directories** — empty `core/`, `plugins/`, `config/` placeholders created per `20_ARCHITECTURE.md`.
