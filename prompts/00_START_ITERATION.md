# Start Iteration

We are continuing development of the Investment Intelligence Platform.

Before doing anything:

1. Read and follow:
   - AGENTS.md
   - WORKFLOW.md

2. Read:
   - progress/CURRENT_STATUS.md

3. If SESSION_HANDOFF.md exists, read it completely.
   Otherwise, read the latest Iteration Checkpoint referenced in CURRENT_STATUS.md.

4. Inspect the repository.

5. Read ONLY the documentation required for the current iteration.

Do NOT write any code.

Instead produce:

## Repository Assessment

- Current milestone
- Current iteration
- Current implementation state

## Understanding

Explain your understanding of the requested work.

## Relevant Documentation

List which documents you read and why.

## Implementation Plan

Include:

- Components affected
- Files to create
- Files to modify
- Dependencies
- Risks
- Assumptions

Estimate implementation size.

If the work is too large for one implementation session, decompose it into smaller logical implementation tasks.

Wait for approval before writing code.
