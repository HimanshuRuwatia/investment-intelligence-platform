# Architecture Consultation

Do NOT write code.

Analyze the requested change against the existing architecture.

Read only the relevant documentation.

Answer:

- Does the current architecture already support this?
- Which existing components should be reused?
- Which documentation governs this area?
- What is the smallest architectural change required?
- What alternatives exist?
- What are the trade-offs?
- What is your recommended approach?

Do not implement anything.

Wait for approval before proceeding.
